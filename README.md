# Code Editor - Live in the Browser

A lightweight browser-based code editor built with **HTML, CSS, and JavaScript** using the **Ace Editor** library.  
It allows you to write, preview, and test HTML/CSS/JS directly in the browser, with options to save and load projects locally.

---

## Features

- Live editing of **HTML, CSS, and JavaScript**
- Real-time **preview** in an iframe
- **Validation tests** support (append JS tests to student code)
- Save work locally as a `.json` file
- Load saved projects back into the editor
- Keyboard shortcuts:
  - `Ctrl + S` → Save project
  - `Ctrl + Enter` → Run preview
- Dark theme UI with teal highlights

---

## Technologies Used

- HTML5 / CSS3 / JavaScript
- Ace Editor (via CDN)
- LocalStorage for caching projects

---

## Getting Started

### 1. Clone the repo

```bash
git clone https://github.com/your-username/code-editor.git
cd code-editor
```

### 2. Open in browser

Simply open index.html in your browser.
No build step or server required — everything runs client-side.

---

## Usage

- Write your assignment/task in the left panel.
- Add optional validation tests in JavaScript.
- Use the tabs to switch between HTML, CSS, and JS editors.
- Click Run to update the preview.
- Save your work locally or load a previous project.
